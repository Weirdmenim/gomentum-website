# Lightweight ADHD UX Update

This update applies the expert review feedback that the homepage felt too noisy for people with ADHD-style overwhelm, low energy, or task-initiation difficulty.

## Main code changes

- Simplified the homepage from a long SaaS-style page into a shorter first-action path.
- Removed the homepage product mockup from the hero so the demo is the clear visual focus.
- Removed the separate before/after section and merged that idea into the demo result.
- Removed the homepage feature grid and feature-status labels. Detailed feature proof remains on `/features`.
- Removed the full homepage task-manager comparison section. A short one-sentence difference remains on the homepage, while deeper explanation stays on inner pages.
- Removed the founder note from the homepage.
- Replaced the large trust-card section with one compact trust strip.
- Reduced the homepage FAQ preview to a single FAQ link.
- Reduced the main desktop navigation to How It Works, Pricing, and FAQ.
- Removed the misleading Log in link because it did not point to a real login page.
- Changed the primary CTA language from “Start One Small Step” to the softer “Try one first move.”
- Added starter chips to the homepage demo so visitors can try the experience without thinking of a task from scratch.
- Changed the demo success CTA from pricing to contact/beta continuation.
- Removed default CTA glow effects and reduced decorative background noise.
- Kept all 13 public routes for SEO, task coverage, and assignment completeness.

## Design direction after update

The homepage now prioritizes:

1. Simple promise
2. One interactive demo
3. Short reassurance
4. Three-step explanation
5. One use-case selector
6. Compact trust strip
7. Soft final CTA

The deeper explanations remain available on inner pages so the site keeps its SEO and grading strength without overwhelming first-time visitors.
