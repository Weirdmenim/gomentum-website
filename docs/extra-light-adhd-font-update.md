# Extra-Light ADHD UX and Font Update

This update makes the Gomentum site calmer and easier to scan.

## Main changes

- Changed the site font stack to Lexend-first with Trebuchet MS and Verdana fallbacks for a warmer, softer, more readable feel without adding a heavy external font dependency.
- Changed the global background from dark to warm cream.
- Made the header light instead of dark.
- Made the hero light instead of dark.
- Reduced homepage sections again.
- Removed the homepage use-case selector to reduce decision load.
- Replaced the homepage trust grid with a short, quiet trust note.
- Reduced large cards, borders, glows, visual weight, and repeated CTAs.
- Kept all 13 routes intact for SEO and task compliance.

## UX intention

The homepage should feel like a calm entrance, not a SaaS pitch deck. The user should see one promise, try one task, and understand one simple flow without needing to process many sections.
