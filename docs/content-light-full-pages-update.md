# Gomentum Content-Light Full Pages Update

This update corrects the previous over-reduction of visible pages.

## What changed

- All 13 public routes remain in the codebase.
- The header now exposes 8 main pages: Home, How It Works, Features, Use Cases, Resources, Pricing, FAQ, and Contact.
- The mobile menu exposes main pages, guide pages, and trust pages in calm groups.
- Footer now includes all public route groups, including ADHD & Task Initiation, Task Paralysis Guide, Privacy, Terms, and Accessibility.
- Page content was made lighter without removing the page structure needed for the task.
- Heavy sections, dense card grids, repeated CTAs, and dark/noisy page blocks were reduced across inner pages.

## Design intent

The site should keep enough pages for SEO, conversion, and grading, while each page feels easier to scan for ADHD-style overwhelm.

The correction is: keep the pages, lighten the content.
